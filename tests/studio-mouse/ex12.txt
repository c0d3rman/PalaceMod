# Example 12: a volcano, built by mouse from an empty level: a status (Burning), two things (a fire area and a
# lava-rock projectile, in the Entity Studio) and a point that lobs rocks at night.
builder-studio new mouse12 Nordfels
sleep 2
builder-studio open mouse12 nordfels-studio
sleep 20
builder-studio cam -4 -40 2
builder-studio press Logic

sleep 1
builder-logic press + status
uikit type Burning
uikit type enter
sleep 1

uikit type enter

uikit type 1
uikit type enter

uikit type enter
builder-logic press + rule
builder-logic press Search
uikit type tick
uikit type enter

builder-logic press + action
builder-logic press Damage
builder-logic press Amount
uikit type 3_*_self.stacks('burning')
uikit type enter
builder-logic press Source
builder-logic press Formula
uikit type other
uikit type enter
builder-logic close

# --- The volcano: a point that, every 12 s at night, launches a lava rock at a random spot within 15 m.
